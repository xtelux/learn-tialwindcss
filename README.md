# learn-tialwindcss
belajar tailwind css


### Instalisasi
Buat folder pembelajaran Tailwind

#### 1. Inisialisasi project
```bash
npm init -y
```

#### 2. Install Tailwind CSS v4
```bash
npm install -D tailwindcss @tailwindcss/cli
```

#### 3. Jalankan compiler
```bash
npm run dev
```

#### 4. Build untuk produksi
```bash
npm run build
